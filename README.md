📊 Sales Performance & Regional Analytics Excel Dashboard
📌 Project Overview
This project delivers a comprehensive, interactive Excel-based sales dashboard designed to track, analyze, and visualize daily business performance. Built using robust spreadsheet modeling techniques, it processes 366 transactional records totaling ₹1,782,570 in revenue across various regions, salesmen, and product categories.

🛠️ Key Features & Architecture
Dynamic Pivot Tables: Aggregates transactional data across multiple dimensions including monthly trends, regional performance, and salesman efficiency.
Interactive Slicers & Filters: Enables users to instantly slice data by region, item category, salesman, and date ranges.
Visualized KPIs & Charts: Features clean graphical charts embedded directly into the dashboard sheet for quick executive summaries.
Structured Workbook Design:
Pivot Tables / Pivot table: Intermediate calculations powering the visualizations.
Dashboard: Front-end executive view with KPI summary cards and dynamic charts.
